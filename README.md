# Personal Finance Tracker

A planned full-stack application for recording expenses, organizing transactions, managing budgets, and understanding personal spending patterns through visual summaries.

## Project Status

Planning — implementation has not started.

## Planned Features

- Record, edit, and delete income and expense transactions
- Categorize transactions
- Filter transactions by date and category
- Set monthly spending budgets
- View spending summaries and category breakdowns
- Display monthly trends using charts
- Persist transaction data in a relational database
- Validate user input and handle errors
- Add automated tests

## Planned Technology Stack

- **Frontend:** React
- **Backend:** Java and Spring Boot
- **Database:** MySQL
- **API:** REST
- **Visualization:** A suitable charting library
- **Testing:** JUnit and frontend testing tools
- **Version Control:** Git and GitHub

- Build a full-stack application

## Future Improvements

Potential enhancements include user authentication, recurring transactions, downloadable reports, and optional data export.

## Scope and Limitations

This project is intended for personal expense tracking and software development practice. It is not a banking application and will not connect to financial accounts unless such integration is explicitly implemented.
